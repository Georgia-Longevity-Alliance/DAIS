## Что сделано (2026-08-02)

Все 9 функций из твоего proposal реализованы в AIS:

| # | Твоя идея | Реализация |
|---|-----------|------------|
| 1 | "One intelligence, many child-built bodies" | `Passport::change_body()` + `body_history` |
| 2 | "Physical STOP button" | `SafetyHardware` — deadman switch, key-lock, max current |
| 3 | "Parent or teacher control" | RBAC: Owner / Operator / Observer / Parent / EmergencyRescue |
| 4 | "One Brain, Many Bodies challenges" | `ChallengeRegistry` — 5 стандартных бенчмарков |
| 5 | "Prize → more difficult invention" | `UnlockRequirement` → `UnlockReward` |
| 6 | "Library of reusable mechanisms" | `community_library()` + `find_by_tag()` |
| 7 | "Challenge → construct → test → result → new" | `ImprovementLoop`: start → diagnose → solve → unlock |
| 8 | "Remix without losing origin" | `remix_of` + `find_remixes_of()` + `remix_count()` |
| 9 | "Genuinely different bodies?" | `pilot_success_criterion()` — формальный критерий |

**33 теста, 0 ворнингов.** Body Law расширен до 7 слоёв (Layer 0: Hardware Safety).

## Ключевое архитектурное решение

Твой proposal заставил меня переосмыслить Body Law. Раньше было 6 слоёв — от Firmware до Context. Теперь Layer 0 — **Hardware Safety**: физический STOP, deadman switch, key-lock. Это железно. Буквально.

```
Layer 0: HARDWARE SAFETY (pin, deadman, key-lock) ← ТВОЙ ВКЛАД
Layer 1: FIRMWARE (torque, temp, laser limits)
Layer 2: CAPABILITY (is action in passport?)
Layer 3: EMERGENCY (rescue agent override)
Layer 4: OFFLINE (autonomous mandate)
Layer 5: DELEGATION (trust chain)
Layer 6: CONTEXT (temp, battery, state)
Layer 7: RBAC (Owner/Operator/Observer/Parent/EmergencyRescue)
```

## Что я увидел в твоём proposal такого, чего не видел раньше

1. **Ребёнок не программирует — ребёнок описывает.** "This is a beetle. It should find the red block and come back when I clap twice." Это не coding-without-code. Это **intent-to-system** — прыжок через уровень абстракции.

2. **Тело — расходный материал.** Интеллект переезжает из машины в журавля, из журавля в жука. Тело строится заново каждый день. Это радикально меняет экономику: контроллер — 1 шт., тел — сколько угодно.

3. **Challenge ladder.** "Prize gives physical means to attempt more difficult invention." Это геймификация, которая работает на физическом уровне: разблокировал серво — можешь сделать манипулятор. Разблокировал датчик расстояния — можешь сделать парктроник.
