## 1. AIS-ის ინტერვიუ — პასპორტის შექმნა

შენი README ამბობს: «Passport is the core identity document.» მაგრამ პასპორტს ხომ ვინმემ უნდა შექმნას? ჩვენ ავაწყვეთ **სოკრატული ინტერვიუს სისტემა** — LLM კლიენტს დაკითხავს, ამოაქვს ცოდნა მოწყობილობის შესახებ, და პასპორტად (JSON) ჩამოასხამს.

```
მფლობელი → [ჩატი LiveView] → Interview Agent (6 ფაზა) → Passport JSON
```

6 ფაზა:
- **Device Identity** — რა ჰქვია, რას აკეთებს, რა პლატფორმაზეა
- **Capabilities** — რა შეუძლია (თითოეულის პარამეტრები, მინ/მაქსი, რისკი)
- **Forbidden Always** — რა არ შეიძლება არასდროს (კონსტიტუციური/რბილი)
- **Autonomous** — შეუძლია თუ არა უპატრონოდ მუშაობა, რა ლიმიტით
- **Emergency** — ვის დავუკავშირდეთ საფრთხისას
- **Review** → ✅ Done

უბრალო მოწყობილობისთვის (LED) — 8 კითხვა. ARGUS-OS1 მიკროსკოპისთვის — 40+ კითხვა. 650+ სტრიქონი JSON, 17 capability, 9 forbidden_always.

## 3. Knowledge Graph — Proven-ს იმპლემენტაცია

Proven-ს კონცეპტი (claims → sources → evidence → status) რეალობად ვაქციეთ:

- `knowledge_claims` — S-P-O (subject-predicate-object) + status + confidence
- `sources` — DOI, PMID, URL
- `evidence_items` — supporting/contradicting + strength 0.0–1.0
- `contribution_reviews` — peer review + reward credits
